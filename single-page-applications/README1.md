# single-page-applications

Source library for conceptual SPAs and reference microsites moved out of `codesbyshrey.github.io`.

## Included Materials

- Conceptual and explanatory single-page apps such as `behavioral-architect`, `interconnected-self`, `living-network`, `quantum-physics`, `cognitive-system-design`, `embodied-agency`, and related pages
- JSX-based experiments such as `bioelectric-levin/index.jsx`
- Support notes including `PASTE-WORKFLOW.md`, `WHY-NOT-FULL-PASTE.md`, and page-local `notfullpaste.txt` files

## Origin Notes

- This folder consolidates materials that previously lived in separate `archive/` and `webpages/` sections.
- The original public-facing GitHub Pages repo no longer acts as the source-of-truth for these SPA files.
